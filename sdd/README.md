# sdd/

SDDs (documentos de especificação, com decupagem) de features — um
arquivo por assunto, escrito pelo chapéu de Game Designer ao abrir um
foco (ver `CLAUDE.md`, seção 6.2).

- **Nome do arquivo**: `sdd-<assunto>.md` (ex.: `sdd-multiclasse.md`).
- **Não é descartável** como `EmDev.md`/`EmDevB.md` — continua valendo
  depois que o foco fecha, como referência de "como essa mecânica
  deveria funcionar". Se um erro for encontrado nele durante a
  implementação, corrija o próprio arquivo (é correção de
  especificação, não uma decisão nova).
- Consultado pelo chapéu de Product Manager (seção 6.1, se já existir
  um de foco anterior) e usado como referência principal pelos chapéus
  de Product/UI Design e Execução (seções 6.3/6.4).
