# livros-referencia/

Pasta pros PDFs originais dos livros de D&D 5e (regras 2024) — Livro do
Jogador e Livro do Mestre. Ver `CLAUDE.md`, seção 3 e 6.1.

- **Fonte de dado que vale sempre**: `dnd-master-referencia.xlsx` (raiz
  do repositório). Os PDFs aqui são referência bruta, nunca sobrescrevem
  o que a planilha diz.
- **Quando usar**: no chapéu de Product Manager (seção 6.1), quando a
  planilha não cobrir o suficiente pra entender a regra por trás de uma
  entrega nova.

## Livro do Jogador — completo (`livro-do-jogador/`)

15 capítulos (regras 2024): Capa/Sumário, Bem-vindo à Aventura, Cap. 1
Jogando o Jogo, Cap. 2 Criação de Personagens, Cap. 3 Classes (2 partes:
Bárbaro a Feiticeiro, Guardião a Paladino), Cap. 4 Origens, Cap. 5
Talentos, Cap. 6 Equipamento, Cap. 7 Magias (2 partes: A-I, I-Z), Ap. A
O Multiverso, Ap. B Estatísticas de Criaturas, Ap. C Glossário de
Regras, Índice.
